# PrintOps 蓝晒制版改版 · 交付说明

日期：2026-10-24 · 分支：`ui/oil-redesign`（未合并 main）· 方法：oil-ui（安装于 `.agents/skills/oil-ui/`）

## 选定方向与理由

**方向 B ·「蓝晒制版」**（用户在对比页后选定）。北极星：制版车间的晒图台——每个字段都带着尺寸与公差的标注，像一张待批注的版面图。探索过程：三家标杆真实截图拆解（Linear/Vercel/Stripe）→ 三个方向文字卡（`design/directions.md`）→ 三个首屏对比页 + 现状基线（`design/candidates/`）→ 用户拍板 B。

## 改了什么

全部改动集中在视觉层，**零业务逻辑改动**：

- `styles.css`（主战场，~60 处）：令牌层整体换血——暖纸/铅字 → 蓝晒图纸（底 `#f4f7f9`、普鲁士墨 `#17304f`、琥珀信号 `#b45309`、钢蓝成功 `#2d6a9f`、锈红危险 `#9a3412`）；新增 `--accent`（主操作结构蓝）与 `--font-mono` 令牌（含 CJK 回退，量词不再落宋体）；圆角 3–8px 锐化；红语义拆分为琥珀信号/锈红危险；衬线标题全部去衬线；PO 徽标、主按钮、用户气泡、选中态、旅程步进改结构蓝；数字/尺寸/金额容器改等宽；身体底纹改极淡蓝晒网格；右栏加图纸裁切角标（CSS 背景层，不随滚动）；状态 chip 全圆改 4px；高对比主题同步换血（主按钮深普鲁士蓝、齿轮白底黑描边、黑白黄语义）。
- `index.html`：`theme-color` 改 `#f4f7f9`；样式表缓存参数 bump。
- `app.js`（1 行）：`LAYOUT_DEFAULTS.sidebarW` 192→232，与 CSS 令牌同步（旧值是左栏标题截断的根因——JS 内联覆盖 CSS）。
- 附带修复（研究清单问题）：左栏标题/历史条目截断、输入框聚焦态误似报错（琥珀→结构蓝）、「信息度 %」与分组序号误用信号色、核对卡行距收紧、「编辑或清空」获得按钮形态。

## 没做什么、为什么

- 不引入框架/构建流程/Tailwind；不改三栏骨架、分隔条、`journey.js` 重挂载、文案、交互；`server.py` 白名单未动。
- 评审指出但**不采纳**的两条：HC 用户气泡纯黑（HC 以最大对比为先，黑白是 HC 标准语言）；比较阶段内容块垂直居中（工作区顶对齐 + 底部动作条是工具惯例，非营销页）。
- 评审指出但**超出视觉范围**（记入待办，不在本分支动）：步骤条激活/顶部阶段标签的同步属既有业务状态逻辑（journey 测试证明行为符合既有预期）；空「依据」行不渲染需改 JS 渲染逻辑；进度条位置调整需改 DOM 顺序；「查看工艺方案」琥珀态规则不一致属既有 JS 状态逻辑。
- 三档半透明表面色（取样 #E8F0F6/#FAFCFE/#F3F8FC）是 `--bg-*` rgba 叠加网格底的自然结果，属登记而非偏离：`--bg-sidebar rgba(228,237,244,.75)`、`--bg-chat rgba(251,253,255,.8)`、`--bg-order rgba(243,248,252,.88)`。
- 动效：未新增（小改动不加；入场 rise/思考点/脉动为既有动效，随主题换色）。
- 文字删减：未删界面文案（评审提到的「现在需要处理」为 JS 渲染文案，超出视觉层）。
