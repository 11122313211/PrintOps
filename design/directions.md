# PrintOps · 三个设计方向（方向卡 · 探索轮）

调性五刻度与标杆取舍共用一份，见 `research.md`。四项差异化检验通过：任意两方向在「首屏骨架 / 字体 / 色彩 / 主视觉」中至多共享一项（A 与 B 共享三栏骨架，其余全不同）；C 为极端方向并打破「后台+聊天」品类套路。

---

## 方向 A ·「暖纸铅印 · 精修」⭐ 推荐

- **北极星**：印厂柜台上那张被翻旧的工单——可靠、纸感、字字清楚；每个面板都像一版排好的活字。
- **生成引擎**：材质 × 环境（纸张与铅字车间）。不是换风格，是把现有品牌资产（暖纸、衬线、品牌红、铅印硬阴影）当资产精修。
- **首屏骨架**：保持现有三栏 + 顶栏，只修比例与密度。
- **字体**：标题继续宋体/Georgia 衬线，建立清晰两级（页面题 衬线大字 / 区块题 加宽字距小帽）；正文不变；**数字与单位引入等宽字体**（尺寸、克重、单号、价格）。
- **色彩**：保留暖纸 + 油墨 + 品牌红，但红降为纯信号色（错误/必填/主按钮），黄铜只用于选中态；新增一档深油墨补次级文字对比。
- **主视觉**：交接单本身——右栏订单草稿做成「一张正在成形的工单」，铅印硬阴影只留给它。
- **控件语法**：小圆角、1px 描边；选中 = 2px 墨线 + 微硬阴影；按钮按下下沉 1px（铅字压印）。
- **记忆点**：确认交接时的「盖章」动效；字段确认时值面出现一次压印痕迹。
- **放弃**：大面积色块、渐变、圆角卡片堆叠、玻璃拟态。

## 方向 B ·「蓝晒制版」

- **北极星**：制版车间的晒图台——界面上每个字段都带着尺寸与公差的标注，像一张待批注的版面图。
- **生成引擎**：材质 × 环境（晒图房 / 蓝晒制版稿）。制版是印刷真实工序，来自产品的证据。
- **首屏骨架**：三栏保留，右栏变为「图纸标注边栏」（与 A 共用骨架 = 唯一共享项）。
- **字体**：全无衬线（PingFang/思源黑体）+ **数字一律等宽**；区块题用 mono 加宽字距，工程图纸语气。
- **色彩**：淡青白纸底 `#f4f7f9` → 普鲁士墨 `#1e3a5f`（文字与结构线）→ 琥珀 `#b45309` 选中与强调（制版遮蔽胶带）；状态用蓝家族深浅，不加新色相。
- **主视觉**：版面尺寸标注语言——字段组外围画尺寸线与端点短杠；页面角落固定裁切/套准标记作为品牌图形。
- **图标**：1.5px 直角描边，制图几何风。
- **控件语法**：2px 小圆角、虚线辅助线；输入框如标注框，左侧色标条表示状态。
- **记忆点**：数量/交期确认时尺寸线从两端合拢；旅程进度做成印张边缘的套准标。
- **放弃**：衬线字体、暖纸纹理、红色信号色。

## 方向 C ·「校样批注台」（极端方向 · 结构性突破）

- **北极星**：编辑桌上摊开的校样页——订单就是那份正在被批注的文档，对话是页边铅笔批注；确认要像「签字付印」。
- **生成引擎**：其他领域媒介（出版校对 / 审阅批注语法）+ 有意打破常规。校对是印刷工业的固有环节，语法来自产品本身。
- **首屏骨架（结构性突破）**：打破三栏后台惯例——中央一张长大的单据文档，字段在文档内直接编辑；聊天退为右侧窄批注栏（审阅模式的 margin comments）；历史与工具收进顶部细条。**实现代价最大**：需改 `index.html` 结构与 `journey.js` 挂载点，部分冒烟测试选择器要同步调整，超出本次「保留骨架」的默认约束。
- **字体**：文档题用重磅黑体，正文 system sans；**批注栏用楷体**（校对铅笔字）；数字等宽。
- **色彩**：冷灰白桌底 `#f7f7f5` + 纯墨黑文档 → 单一强调 = 校对荧光黄（未决项像荧光笔划过）；红只留给印章与删除线。
- **主视觉**：校对符号语言——插入符、删除线、页边竖线；未确认字段在页边留「待批注」空位。
- **图标**：不用图标，用校对符号与编号。
- **控件语法**：文档内联编辑（虚线下划线提示可编辑）；批注无边框，靠楷体与缩进识别；主按钮 = 墨黑「签字」按钮。
- **记忆点**：逐项确认后页边批注划掉淡出；全部确认时文档盖「可以付印」章。
- **放弃**：侧栏、卡片容器、进度块——一切把文档推离舞台中央的东西。

---

## 推荐理由

**推荐 A**。你的诉求是「优化 UI」而非换脸：暖纸 + 衬线 + 品牌红的身份已被截图验证为统一且成立，A 修掉全部已确认问题（截断、层级平、状态弱、密度失衡、次级文字对比低），实现完全落在令牌层 + 组件 CSS，与「保留三栏骨架 / 测试 / 高对比主题」的约束零冲突，风险最低。想换一套全新观感但保持同等实现安全，选 B。C 辨识度最高，但要动结构与测试，需要放宽本次约束。
