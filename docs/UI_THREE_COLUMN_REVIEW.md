# 三栏布局与对话面积调整

日期：2026-10-16。依据用户对顶栏拥挤、对话与输入空间的反馈实施，仅调整位置和 CSS。

## 结果

- 左栏顶部放品牌，移除占据整屏顶部的英文宣传行；在线状态、高对比和模型接口设置集中在左栏底部。
- 左栏中段独立滚动，品牌和设置保持可达。手机从现有导航按钮展开左栏即可使用设置。
- 中间保留现有对话标题、消息和输入框；不再扣除全局顶栏高度。右栏继续展示订单参数与原有资料入口。
- 本批不改变左右栏默认宽度、用户折叠偏好或拖动逻辑。产品差异仅为 `index.html`、`styles.css`；`app.js`、`journey.js` 与本批起点逐字相同。

## 空间测量

两种浏览器使用同类合成空单、相同视口和栏位偏好。下表以 Chromium 为例，WebKit 在相同尺寸得到相同的 68px 增量，仅有亚像素差异。

| 视口 | 调整前聊天记录区 | 调整后聊天记录区 | 输入框区域 |
| --- | --- | --- | --- |
| 1440 × 900 | 497px | 565px | 107px |
| 390 × 844 | 455px | 523px | 107px |
| 320 × 568 | 179px | 247px | 107px |

输入区高度及发送按钮底部位置保持原值，新增高度全部给聊天记录区。六组测量均无页面横向溢出，发送中心可命中。证据：[调整前](../reports/ui-position-tuning/three-column/baseline/geometry.json)、[调整后](../reports/ui-position-tuning/three-column/after/geometry.json)。

## 回归与独立 review

| 检查 | Chromium | WebKit |
| --- | --- | --- |
| UI 位置与交互完整专项 | 首次 14/15 | 15/15 |
| 入口与焦点完整专项 | 14/14 | 14/14 |
| browser smoke | 8/8 | 8/8 |
| 最终短横屏修补后定向复验 | 1/1 | 1/1 |

首次唯一失败是 844 × 390 下滚动到发送按钮后，其底部超出视口约 0.27px。为短屏滚动容器设置 16px 滚动留白后，两浏览器复验通过，没有放宽断言。现有两浏览器各 37 个相关用例均已有通过证据，复验的横屏用例不重复计为新用例。

独立 review 发现并复核修好了旧顶栏浅色文字样式覆盖。最终检查包括两浏览器共 8 组尺寸/侧栏状态，以及短横屏“示例闭合、展开、长输入”共 6 个状态：

- 180px 左栏品牌无裁切，按钮高 44px，最长“接口已启用”文字可容纳。
- 底部设置不随左栏内容滚动；手机首末 Tab 循环、键盘打开接口弹窗、Escape 返回设置入口正常。
- 默认底部按钮文字对比约 6.89，高对比模式为黑白；在线状态可读。
- 短横屏发送按钮完整可见，中心及底部内侧可命中；未出现额外 POST 或 JS 异常。
- 没有残留的全局顶栏或旧顶栏高度扣减。

另外的隔离交互走查在最终源码上完成 94/94 项检查，覆盖两浏览器三种尺寸：实际拖动两侧栏宽至边界并双击重置、收放、真实合成聊天形成长记录后滚动、左栏内容滚动与固定品牌/设置、手机订单往返及草稿保留。测试准备后的纯 UI 操作中，完整订单快照与 revision 不变，POST、下载及页面错误均为 0。这里的 94 项是同一走查中的检查点，不作为 94 名用户或 94 个独立自动化用例。详见[隔离验证说明](../reports/ui-position-tuning/three-column/VERIFICATION.md)及[原始记录](../reports/ui-position-tuning/three-column/interactions/verification.json)。

版本边界：完整套件执行跨越了按钮配色小修补；最终短横屏 CSS 修改后只复验了对应两项。六张常规尺寸截图早于最后的短横屏专用规则，该规则只作用于宽度不超过 1050px 且高度不超过 480px。最终源码、哈希、完整报告位置及本批差异见 [verification.json](../reports/ui-position-tuning/three-column/final/verification.json)，不把历史报告说成全部在同一个最终哈希下运行。

测试使用临时存储和隔离服务，不向现有业务订单写试验数据。真实手机软键盘、系统输入法和原生浏览器缩放仍沿用原计划单独验收，本批无头浏览器结果不替代这些检查。
