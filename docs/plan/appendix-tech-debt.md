## B.6 登记流程

1. 新债务：在本文件对应小节追加一行（编号 TD-续），描述必须含可定位的文件/行为；
2. 评估：是否纳入已有路径的任务卡（写归属与卡号），或标"待排期"；
3. 偿还：状态改"已完成 vX.Y.Z"，并迁移到 B.5 趋势表；
4. 每版本发布评审时过一遍本登记册，"待排期"超过三个版本仍未入路径的条目升级为活跃风险（进附录 A）。
