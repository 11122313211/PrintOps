# 附录：风险登记册与监控点（appendix-risk-register）

> 本附录是总纲 5.2 的展开。每条风险给出：编号、所属路径、描述、概率/影响、缓解措施、
> **触发信号**（何时知道风险正在发生）与**监控点**（用什么手段持续观察）。
> 执行期每两周评审一次：触发信号出现的风险升级为"活跃"，活跃风险必须有负责人与应对时限。

## A.12 监控汇总（工程化最小集）

本地工具不做遥测，"监控"由以下四类手段构成：

1. **测试与评测门禁**（CI 每次运行）：149+ 单测、合成/真实评测、secret_scan、axe 扫描；
2. **运行轨迹与会话数据**：runHistory/audit_log 是本地的"可观测性"，排障入口；
3. **版本趋势**：`evaluate_agent --record` 的 history.jsonl 序列；
4. **人工走查**：RELEASE_CHECKLIST 门槛 7 的定期重放（每个 minor 版本一次）。

每条路径的阶段完成时，把上述对应监控点接入（多数是测试，少量是运行时埋点如降级率 console 计数）。
