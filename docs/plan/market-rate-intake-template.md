# 市场标定采集模板（rate card "公开挂牌参考价" intake）

> 用途：把各平台公开挂牌价采集结果转成 PrintOps rate card（schema 3.0）可标定的
> 结构化条目。每品类一张表，一行一个数据点。原始证据（截图明细行原文、日期、
> 采集方式）保留在 docs/plan/sd2000-price-probe-2026-11-21.md 及后续 probe 文档，
> rate card sources 引用 probe 文档路径 + 品类锚点。
>
> 本期（2026-11-21）已采平台：sd2000.com（盛大印刷，河南永城）——
> 全站 JS 渲染，采集方式=Computer Use 真实浏览器实测（非爬虫），未登录产品详情页。

## 一、来源类型与口径规则（所有条目强制携带）

| 字段 | 规则 |
| --- | --- |
| sourceType | 固定 `公开挂牌参考价`（不用"市场价/供应商报价"——非授权非成交价） |
| platform | 域名+平台名（如 `sd2000.com 盛大印刷`）；每品类锚定一家，跨平台价差写入估算区间宽度依据 |
| observedAt | 采集日期 ISO 格式 |
| method | 采集方式（`人工驱动浏览器实测` / `用户口头提供` / `平台客服口径`） |
| priceScope | 价格口径四问：①含税？②含运费？③起订量？④工艺组合（配置明细行原文照抄） |
| listedPrice | 平台展示总价（不拆分、不改写；换算单价仅作参考列） |
| manualOrderDelta | 人工/电话接线价与自助下单价的差（sd2000 实测 +4~11%） |

口径未知项（含税与否）标 `unknown`，不猜测。sd2000 已证口径：
挂牌价=自助网络下单价；**不含目的地运费**（发货地未选时照常出价，运费栏空置）；
是否含税 unknown；截稿时间/出货工期随品类与数量档变化（名片 18:30、展板 11:30、
宣传单 18:00、不干胶小量 12:00 大量 18:00、卡盒 18:00）。

## 二、每品类采集表模板

```
### <品类名>（PrintOps family: <family>；锚定平台: <platform>）

基线配置：<材料/尺寸/印面/印色/关键工艺——与 PrintOps 品类参数口径对齐>

| 数量档 | 挂牌总价 | 折合单价 | 人工接线价 | 重量 | 工期 | 口径备注 |
| --- | --- | --- | --- | --- | --- | --- |

形态判定：纯线性 / 基础费+边际 / 阶梯缓降（勾选并写边际值）
工艺灵敏度：<有实测的轴写实测值，无实测写"未采">
```

- 数量档至少 2 点（判定形态），最好 3 点（低/中/高档）。
- 工艺灵敏度只采对 PrintOps 参数有镜像的轴（如板厚、印面、印刷类型、包装）。

## 三、形态判定 → schema 3.0 驱动映射（拟合规则）

| 观察形态 | 判据 | rate card 驱动 |
| --- | --- | --- |
| 纯线性 | 总价=k×量，档间零折扣 | 面积/单价 × 数量（既有结构） |
| 基础费+边际 | 首档单价显著高于边际 | batchSetup（批次开机费）+ 按量边际 |
| 阶梯缓降 | 折合单价随档位单调下降 | quantityTiers（设备阶梯） |
| 工艺轴跳变 | 换工艺档总价跳变（非加价） | 该工艺进 requiredDrivers 定价项 |

本期 sd2000 实测形态归属：名片=纯线性（0.05/张，单双面同价）；展板(PVC)=基础费+边际
（边际≈12.5/张）+板厚轴（5MM/3MM=1.235）；宣传单=阶梯缓降（0.110→0.085/张）；
不干胶=基础费+边际（100→200 边际 1.30 元，≥1000 后 0.016/张线性）+印刷类型轴
（合版×1/数字×2.7/专版×50）；骑马订画册=batchSetup 主导（制版摊薄，数字/胶印
交叉点 100~500 本）；卡盒=batchSetup（刀版摊薄，10 倍量 5.3 倍价）+期货服务
（延 1 天约 -2%，交期调价维度）。

## 五、标定与复核流程

1. 新数据点先补 probe 文档（含配置明细行原文），再按本文模板建/更新品类表；
2. 拟合用 `tools/calibrate_pricing.py`（CalibrationTest importlib 加载），
   按"形态判定"选驱动，逐 lineItems 手算核对（对齐 pricing-worked-examples 惯例）；
3. rate card version bump 后 `tools/knowledge_review.py` 复核日同步；
4. **季度复核**：ride 现有 90 天 knowledge_review 周期——到期重访锚定平台
   同配置抽 2 档复价，偏差 >15% 触发该品类重标定并在 sources 注记；
5. 用户口头提供的价格（供应商报价）单独 sourceType 录入，不与公开挂牌价混表。
